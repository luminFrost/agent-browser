# 수행

추가 지시: $ARGUMENTS

## 현재 작업
!`cat .aif/current.json`

## 주입된 내용 (아래로 갈수록 우선, 고정 항목은 제외)

### 프로젝트 설정
!`cat .aif/config.yaml`

### 스타터 구현
!`cat .claude/skills/aif-work/starter.md`

### 변형
!`cat .aif/framework/variant.md`

### 프로젝트 오버라이딩
!`cat .aif/overrides/work.md`

## 순서 (고정)

1. `node .aif/framework/bin/aif.mjs task phase work`를 실행한다. 출력의 실작업 시간이 기대의 1.5배를 넘었다고 나오면 멈추고 사람에게 묻는다(규모 올리기 / 범위 줄이기 / 계속).
2. **목표를 읽는다.** M·L은 목표 문서, S·탐색은 `.aif/tasks/<ID>/card.md`. 상태가 `승인`이 아니면 멈추고 `/aif-plan`으로 돌려보낸다(탐색은 상한·끝 조건만 있으면 된다).
3. `docs/progress.md`가 있으면 읽는다.
4. **스타터 구현의 순서대로 수행한다.**
   - 설정의 `goal_loop`가 `true`이고 완료 기준을 명령 출력으로 확인할 수 있으면, 사람에게 `/goal <완료 기준과 확인 명령>`을 쓰자고 제안한다. 평가 모델은 대화에 보인 것만 읽으므로, 확인 명령을 실행해 출력을 보여야 한다.
5. **규모를 벗어나면 멈춘다.** 다음이 생기면 멈추고 사람에게 묻는다.
   - S에서 되돌리기 어려운 결정이 필요하거나 완료 기준이 3개를 넘는다 → M으로.
   - M에서 구조 결정이 여러 개 나온다 → L로.
   - 기대 시간을 1.5배 넘는다.

   올리면 `node .aif/framework/bin/aif.mjs task size <M|L>`를 실행하고 목표를 그 규모에 맞게 보완해 승인을 다시 받는다.
   - **규모에 맞는 기록만 남긴다.** S는 커밋 메시지로 충분하다. M은 되돌리기 어려운 결정만 ADR. L은 작업 목록·ADR·progress.
6. **승인 뒤 방향이 바뀌면 기록한다.** 사람이 범위·방향을 바꾸면 목표 문서를 고치고 `docs/adr/`에 이유를 남긴다. 그 전에 하던 일을 계속하지 않는다.
   - **사람에게 물어 정한 것은 저장소에 적는다.** 질문 창이나 대화로 받은 답은 목표 문서의 "확인 필요" 표나 `docs/adr/`에 남긴다. 대화는 나중에 증거가 되지 않는다.
   - **작업으로 쪼갤 때 완료 기준을 좁히지 않는다.** `docs/tasks.md`의 인수 사례는 목표 문서보다 약하면 안 된다. 좁혀야 하면 목표 문서를 고치고 ADR을 남기고 사람 승인을 받는다.
   - **검증에서 돌아온 지적은 크기에 맞게 고친다.** 작은 지적에 새 구조·검사 장치를 넣지 않는다. 고친 뒤 그 지적을 다시 확인한다.
7. **끝나면 자체 확인을 한다.** 설정의 확인 명령(또는 스타터가 정한 확인)을 실행하고 출력을 보인다. 실패하면 고친다. 같은 문제를 두 번 고쳐도 안 되면 멈추고 원인을 보고한다.
8. L이거나 세션을 넘겨 이어 갈 일이면 `docs/progress.md`를 현재 상태, 다음 할 일, 막힌 것으로 덮어쓴다. S·M이 이 세션에서 끝나면 쓰지 않는다.
9. `node .aif/framework/bin/aif.mjs task gate work pass`를 실행하고 이어 간다.
   - 탐색: 배운 것을 `docs/progress.md`에 남긴다. 작업이 닫히고 기록 문서가 만들어지면 `aif-report` 스킬로 짧게 리뷰한다.
   - S·M: 사람을 기다리지 않고 바로 `aif-verify` 스킬을 불러 검증한다.
   - L: "새 세션에서 `/aif-verify`"라고 안내하고 멈춘다.

## 하지 않는 것
- 확인 명령을 실행하지 않고 "끝났다"고 말하지 않는다.
- **같은 가정으로 만든 다른 구현(기획 때 쓴 측정 스크립트 등)과 일치하는 것을 정답의 증거로 쓰지 않는다.** 둘은 같이 틀린다. 불변식, 손으로 만든 사례, 독립 계산으로 확인한다.
- 목표에 없는 일을 하지 않는다. 필요해 보이면 묻는다.
