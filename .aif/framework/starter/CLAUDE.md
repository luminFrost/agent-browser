# 개발 스타터 지시 (프레임워크 소유, 프로젝트에서 고치지 않음)

- 작업은 `/aif-plan`으로 시작한다. 무엇을 만드는지의 정본은 표준 경로는 `docs/spec.md`, 가벼운 경로는 `.aif/tasks/<ID>/card.md`다. 승인 전에는 구현하지 않는다.
- 작업마다 완료 기준으로 실패하는 테스트를 먼저 쓰고, 통과시키는 최소 구현을 한 뒤 커밋한다. 커밋 메시지의 `Task: <ID>` 트레일러는 git 훅이 붙인다.
- 테스트를 지우거나 skip·only로 끄지 않는다. 필요하면 이유와 함께 묻는다.
- "끝났다"고 보고하기 전에 확인 명령(`.aif/config.yaml`의 `commands`)을 실행하고 출력을 보인다.
- 검증은 독립된 증거로 한다. 표준은 reviewer 또는 새 세션, 가벼운은 확인 명령의 출력이다.
- 운영 환경·main 브랜치에 직접 닿는 명령은 실행하지 않는다. 배포는 사람 승인 뒤 CI가 한다.
