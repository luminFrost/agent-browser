# 변형: 앱 (모바일·데스크톱)

## 기획에서 물을 것
- 대상 플랫폼과 최소 OS 버전
- 화면 흐름과 상태(로딩, 빈 상태, 오류, 오프라인)
- 권한(카메라, 위치, 알림)이 필요한가
- 스토어 심사나 서명이 필요한 변경인가

## 수행에서 지킬 것
- 플랫폼 공통 컴포넌트와 테마를 쓴다.
- 서명 키·스토어 자격 증명은 에이전트가 다루지 않는다.

## 검증에서 할 것
- 에뮬레이터·시뮬레이터에서 바뀐 흐름을 실행하고, 상태별 스크린샷을 남긴다.
- 실기기에서만 확인할 수 있는 것(성능, 센서)은 "확인 못 함"으로 두고 사람에게 넘긴다.

## 전달에서 할 것
- 빌드 산출물과 버전 번호를 기록한다. 스토어 제출은 사람이 한다.
