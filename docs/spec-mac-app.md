# Spec: Mac 앱(.dmg)으로 묶기
상태: 승인 (2026-11-14) · 구분: 남길 것 · 정본: 이 문서 (앱 동작의 정본은 `docs/spec.md`) · 규모: M · 검증 강도: 엄격 · 작업: 20261114-mac-app-package

## 가치
다른 Mac에서 소스·Node·npm 없이 dmg를 받아 더블클릭만으로 에이전트 브라우저를 쓴다. `npm start` 없이 바로 쓸 수 있게 한다.

## 범위
- 한다:
  - `npm run dist`로 Apple Silicon(arm64)용 `.app`과 `.dmg`를 만든다. 파일 이름에 버전이 들어간다.
  - 묶은 앱 안에서 런처와 브라우저가 지금 구조 그대로 돈다. 런처가 파이프로 브라우저 CDP를 쥔다(ADR-0002). 런처는 같은 앱 실행 파일을 Node 모드로 띄워 돌린다.
  - 앱을 이미 켠 상태에서 다시 열면 새로 띄우지 않고 기존 사람 창을 앞으로 가져온다.
- 안 한다:
  - Apple 서명·공증(사람 결정 2026-11-14: "서명 없이"). 처음 열 때 우클릭 → 열기로 허용한다.
  - Intel Mac·Windows 빌드(사람 결정: "Apple Silicon만").
  - 자동 업데이트, 앱 아이콘 디자인, 배포 서버.
  - 앱 동작(R1~R13) 변경.

## 요구사항과 인수 사례 (= 완료 기준)
| # | 요구사항 | 인수 사례 (입력 → 기대 결과) | 확인 방법 |
|---|---|---|---|
| P1 | 묶기 | `npm run dist` → `release/` 아래에 arm64 `.dmg`와 `.app`이 생기고, 파일 이름에 `package.json`의 버전이 있다 | 명령 출력 + 파일 목록 |
| P2 | Node 없이 실행 (정상) | PATH에서 node·npm을 뺀 환경에서 묶은 앱 실행 파일을 띄운다 → 사람 창이 뜨고 프로필에 `control.json`(0600)이 생긴다. 그 port·token으로 `POST /sessions`를 보내면 `browserUrl`이 오고, Playwright `connectOverCDP`로 붙어 페이지를 연다 | E2E(묶은 앱 대상) + 화면 캡처 |
| P3 | 보안 불변식 유지 | P2 상태에서 → 앱의 어떤 프로세스도 127.0.0.1 밖에서 LISTEN하지 않고, 브라우저 프로세스는 TCP 디버그 포트를 열지 않는다. 토큰이 없으면 401이 온다 | E2E + `lsof` 출력 |
| P4 | 끝내기 (경계) | 사람 창을 닫거나 앱을 종료한다 → 런처·브라우저 프로세스가 모두 사라지고 남는 프로세스가 없다 | E2E(프로세스 목록) |
| P5 | 두 번 열기 (경계) | 앱이 켜진 상태에서 다시 실행한다 → 두 번째 런처·브라우저가 생기지 않고, `control.json`은 그대로이며, 기존 사람 창이 앞으로 온다 | E2E |
| P6 | 브라우저 비정상 종료 (오류) | 묶은 앱의 브라우저 프로세스를 강제로 죽인다 → 런처도 끝나고 남는 프로세스가 없다. 다음 실행은 정상으로 뜬다 | E2E |
| P7 | 기존 동작 유지 | `npm test`·`npm run lint`·`npm run build`·`npm start`가 그대로 통과·동작한다 | 확인 명령 |

## 제약
- 기술·환경: macOS, Apple Silicon. 묶기 도구는 `electron-builder`(MIT, 새 devDependency. 계획 승인 때 함께 승인 2026-11-14)를 쓴다.
- 보안·권한: ADR-0002를 유지한다(TCP 디버그 포트 없음, 원본 CDP는 런처만 쥠). 서명 키는 다루지 않는다.

## 상한 (완료 기준이 아니다)
- 시간: 120분(설정 budgets.M). 재는 방법: 프레임워크 실작업(5분 넘는 빈 시간 제외)
- 토큰: 2,000,000. 재는 방법: 캐시 읽기 제외

## 위험
- 실제 데이터·결제·인프라에 닿는가: 닿지 않는다. 로컬 빌드 파일만 만든다.
- 앱 실행 파일을 Node 모드로 띄울 수 있게 둔다(런처용). 같은 Mac의 사용자가 이 앱으로 Node 코드를 돌릴 수 있게 되지만, 그 사용자는 이미 로컬에서 코드를 돌릴 수 있으므로 새 권한은 아니다.
- 알려진 한계(ADR-0008, 검증 3회차): 앱을 끈 직후 약 0.02초 안에 다시 열면 열리지 않을 수 있다(다시 열면 된다). 실행 중인 프로필 폴더를 통째로 복사해 쓰면 복사본이 열리지 않을 수 있다(`launcher.lock`을 지우면 된다).
- 되돌리는 방법: 앱을 지우면 된다(`/Applications/Agent Browser.app`). 프로필은 `~/Library/Application Support/agent-browser`에 그대로 남는다. 지우면 로그인 상태도 사라진다.

## 확인 필요
| 추정 항목 | 영향 주는 곳 | 누가 확인 |
|---|---|---|
| 회사 PC가 서명 없는 앱 실행을 막는지 | 다른 PC에서 쓰기 | 사람 (받는 PC에서 한 번 열어 본다. 막히면 서명을 새 작업으로) |
| 묶은 앱에서 다른 PC의 기존 프로필 경로가 같은지 | P2 | 수행 중 확인 (`defaultProfileDir` 그대로 쓴다) |
