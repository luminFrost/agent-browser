잘 된 것

  • 빈틈이 나올 때마다 그 빈틈을 잡는 테스트부터 만들고 고쳤습니다. 그래서 같은 문제가 다시 생기지 않습니다.
  • "이건 설계상 완전히 막을 수 없다"는 문제는 제가 마음대로 정하지 않고 당신에게 물어서 정했습니다.

아쉬웠던 것과 이유

  • 검사를 다섯 번 해야 했습니다. 계획 단계에서 막을 범위를 정하지 않았습니다. (원인: 계획 때 빠진 질문)
  • 처음에는 "막을 것 목록"으로 만들어서 빈틈이 생겼습니다. 세 번째 검사 뒤에 "허락할 것 목록"으로 바꾸자 빈틈이 멈췄습니다. (원인: 만드는 방식)
  • 보고서가 어려웠습니다. 내부 용어가 섞인 md 파일로 드렸습니다. (원인: 보고 방식이 정해져 있지 않음)
