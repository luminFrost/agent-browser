Mac 앱 묶기 — 마무리와 돌아보기

2026-11-15 · 작업 20261114-mac-app-package · 닫힘

결론: 작업을 닫았습니다. 결과물은 release/Agent Browser-0.1.0-arm64.dmg(버전 0.1.0)입니다. 예상 2시간에 약 1시간 52분이 걸렸습니다. 고르신 개선 4건은 모두 기록했습니다.

지금 하실 일

  1. main에 합치기. 터미널에 ! git checkout main && git merge --ff-only feat/mac-app를 입력하세요. main에 쓰는 명령은 규칙상 제가 하지 않습니다.
  2. 앱 직접 열어 보기. dmg를 열고, 처음 한 번은 앱을 우클릭 → 열기로 엽니다. 회사 PC에서도 열리는지 확인해 주세요.
  3. 다음 작업 시작. /aif-plan 런처 자물쇠 3건 고치기를 입력하세요. 이미 고르신 대로(3건, 규모 S, 검사 보통) 바로 엽니다.

무엇이 있었나

  • 계획 승인 → 만들기 → 검사 3번 → 마무리.
  • 검사 1·2회차 실패는 모두 "두 번 열어도 하나만 뜬다"였습니다. 2회차 뒤 고르신 A안(앱이 직접 판단)으로 바꾸어 3회차에 통과했습니다.

왜 두 번 실패했나

  • 계획에 기준이 없었습니다. "다시 실행한다"만 있었고, 얼마나 빨리, 몇 번 연속인지가 없었습니다. 그래서 검사할 때마다 더 빠른 경우가 새로 나왔습니다.
  • 첫 구현에 빈틈이 있었습니다. "켜져 있음" 표시를 놓은 뒤에 프로그램을 띄워, 그 사이로 하나가 더 들어왔습니다.
  • 남은 비슷한 빈틈 하나(강제 종료 뒤 동시에 여러 번 열기)는 다음 작업에서 고칩니다.

번호내용상태
