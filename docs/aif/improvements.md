# 개선 목록

실행 → 리뷰 → 개선. 리뷰(/aif-report)에서 나온 "다음에 바꿀 것"을 모은다. `aif improve`가 다시 쓴다.
- 프로젝트 범위: 이 프로젝트의 설정·규칙·오버라이딩에 반영한다.
- 프레임워크 범위: `aif improve export`로 ~/.aif/inbox에 보내고, 프레임워크 저장소에서 `aif inbox`로 여러 프로젝트의 것을 모아 본다.
