# ADR-0011: 2차 범위는 꼭 필요한 Chrome 기능과 직접 만든 확장만, 페이지 도구는 보이는 탭에만 붙인다
상태: 승인 · 날짜: 2026-11-27 · 작업: 20261127-page-devtools

## 맥락
- 1차(v0.2.x)로 사람 창 + 세션 묶음 + 승인 관문이 돌고, 북마크(v0.2.8~)와 앱 안 업데이트(ADR-0010)가 들어왔다. `docs/spec.md`의 "안 한다"에 북마크·브라우저 확장·자동 업데이트가 그대로 남아 있었다(설계서 DF-08·09).
- 사람 결정(11-27): "크롬의 모든 기능들을 가져올 건 아니고 꼭 필요한 것만". 확장은 "일단은 내가 직접 만든 것만 연결". 후보 27개 중 8개를 골랐다(설계 DOC-10-PLN, DOC-01-SD 7장).
  - v0.3: 개발자도구(F-BR-06), 보는 세션 탭 개발자도구(F-HW-13), 오른쪽 클릭 메뉴(F-BR-07), 페이지 안 찾기(F-BR-08), 확대·축소(F-BR-09)
  - v0.4: 직접 만든 확장(F-BR-12), 탭 복원(F-BR-10), 방문 기록·주소 자동완성(F-BR-11)
- 위험: 페이지 도구가 보는 중인 에이전트 탭에 사람 입력을 넣는 새 길이 될 수 있다(RK-17, ADR-0009의 입력 잠금 우회). 개발자도구가 에이전트 CDP와 부딪힐 수 있다(RK-16). 배율이 같은 출처의 에이전트 탭에 번진다(RK-18).

## 결정
1. **범위(P-12·P-13):** Chrome 기능은 위 8개만 넣는다. 동기화·비밀번호 관리자·웹 스토어 확장은 여전히 안 한다. 확장은 사람이 메뉴로 등록한 압축 푼 폴더만 읽는다(v0.4, 에이전트 CDP로는 등록 못 함).
2. **개발자도구는 별도 창(D-5):** `webContents.openDevTools({ mode: 'detach' })`. 사람 창 안에 붙이면 탭 크기가 바뀌어 보이지 않는 세션 그리기(구석 1px, ADR-0009)를 다시 짜야 한다. 창 UI(`win.webContents`)에는 열지 않는다(앱 메뉴에 `toggleDevTools` 역할을 두지 않는다).
   - 대상은 지금 보이는 탭 하나: 내 탭을 보면 내 활성 탭, 세션을 보면 그 세션의 보이는 탭(F-HW-13, 보기만 하는 도구).
   - 세션 탭의 개발자도구는 그 세션을 보는 동안만 연다. 내 탭으로 돌아오거나 다른 세션으로 옮기면 닫고, 세션이 끝나면 탭과 함께 닫힌다.
   - Chromium 안쪽 연결이라 TCP 디버그 포트를 열지 않고(ADR-0002 그대로), 런처 프록시가 거르는 에이전트 대상 목록(`/json/list`, `Target.getTargets`)에도 나오지 않는다. 실험(11-27, Linux)에서 연 채로 에이전트 이동·클릭·스냅숏·스크린샷이 됐다(RK-16). E2E `pageTools.spec.ts` D1·D2가 고정한다.
3. **세션을 보는 중 오른쪽 클릭은 "검사" 하나(D-6):** 세션 탭의 사람 마우스는 이미 막혀 있다(`before-mouse-event`, ADR-0009). 막은 오른쪽 누르기를 사람 창이 받아 "검사"만 띄운다. 페이지는 `contextmenu`·`mousedown`을 받지 않는다. 내 탭은 링크·이미지·선택 글자·입력 칸·그 밖에 맞춘 메뉴 + 검사(`src/browser/pageMenu.ts`). "새 탭에서 열기"는 http·https·data·blob만(그 밖은 꺼서 `javascript:` 등을 열지 않는다), 바로 오른쪽에 열고 활성 탭은 그대로.
4. **찾기·확대는 내 탭만(D-7):** 세션을 보는 중에는 하지 않는다(읽기 전용 유지).
5. **확대는 CSS 확대(D-8, 사람 결정 11-27):** Chromium 배율은 같은 출처의 다른 탭(에이전트 탭 포함, 같은 `persist:shared`)에 번지고, 탭 기본 배율로는 못 막는다(실험). 그래서 사람 탭 문서에만 `insertCSS("html { zoom: N !important }", { cssOrigin: 'user' })`를 넣고, 배율은 호스트마다 `zoom.json`에 둔다. 대가: 화면 폭이 바뀌지 않아 반응형 배치는 바뀌지 않는다.

## 결과
- `docs/spec.md` "안 한다"에 바뀜 표기: 북마크(v0.2.8~), 직접 만든 확장(v0.4), 앱 안 업데이트(ADR-0010, 저절로 깔지는 않음).
- 사람이 보는 세션 탭의 개발자도구로 그 페이지에 스크립트를 실행할 수 있다. 사람이 고른 도구이고 에이전트 쪽 권한은 늘지 않는다. 보는 동안만 열려 있게 해서 모르는 사이 남지 않게 한다.
- macOS에서 별도 창 개발자도구와 에이전트 동시 사용은 회사 PC 확인표(v0.3)로 본다.
