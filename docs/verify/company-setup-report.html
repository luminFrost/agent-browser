회사 PC에서 Claude가 설치하고 쓰기 — 검사 결과

2026-11-15 · 작업 20261115-company-setup · 2회차 검사에서 통과 · 실작업 약 36분

결론: 회사 PC에서 GitHub으로 받은 저장소를 열고 Claude에게 "docs/setup.md대로 설치해 줘"라고 하면, Claude가 빌드·설치·등록·확인을 끝까지 합니다. 빌드가 막히면 GitHub Release의 dmg로 설치합니다. 다른 프로젝트에서 이 브라우저를 쓰는 Claude는 붙는 순간 "쓸 때 알 것"을 안내로 받습니다.

지금 하실 일

  1. /aif-deliver를 입력하세요. 승인을 받은 뒤 작업을 닫습니다. 그다음 ! git checkout main && git merge --ff-only feat/company-setup으로 합치시면 됩니다.
  2. GitHub에 비공개 저장소를 만들고 main만 push하세요. 
    git remote add origin <저장소 주소>
git push -u origin main
    앞서 만든 docs/install-guide 브랜치는 이 Mac의 개인 경로가 들어 있고 이번 작업으로 대체되었으니 올리지 마세요. 지우려면 git branch -D docs/install-guide를 실행하시면 됩니다.
  3. 회사 PC에서: 
    git clone <저장소 주소> agent-browser && cd agent-browser
claude
    그리고 Claude에게 "docs/setup.md대로 agent-browser를 설치해 줘"라고 말하세요. Claude가 끝나면 앱을 한 번 열고(막히면 우클릭 → 열기), 회사 계정에 로그인하면 됩니다.
  4. Claude가 "빌드가 막혀 Release가 필요하다"고 하면, 이 Mac에서 docs/setup.md의 "Release 올리기" 명령을 실행해 주세요.

된 것

바라던 것결과
회사 PC의 Claude가 읽고 따라 할 설치 절차통과 — docs/setup.md. 단계마다 성공 판단과 실패 때 할 일이 있고, CLAUDE.md가 이 문서를 가리킴
설치를 한 번에 해 주는 스크립트통과 — 깨끗한 저장소에서 실제로 빌드부터 등록까지 성공(검사에서는 가짜 claude와 임시 폴더를 써서 선생님 설정은 안 건드림)
빌드가 안 되면 Release dmg로통과 — Node가 없는 환경에서 dmg로 설치 성공
조건이 안 맞으면 아무것도 바꾸지 않고 이유를 알림통과 — Apple Silicon 아님, claude 없음, Node 없음·낮음
다른 프로젝트에서 쓸 때 Claude가 알 것통과 — 붙는 순간 안내를 받음: 자기 창만 보임, 회사 계정을 함께 씀, 폼 제출·다운로드는 사람 허용 대기, 허용 창은 보조일 뿐이라 위험은 스스로 판단, 막힌 도구, 끊기면 /mcp
GitHub에 올리면 안 될 것통과 — 대화 기록(.aif/tasks)과 .DS_Store 제외, 추적 파일에 개인 경로·이메일·토큰 없음
기존 기능통과 — 테스트 281개, 묶은 앱 테스트 16개

1회차에서 걸린 것

설치 문서의 Release 받기 명령이 dmg 이름 Agent Browser-…(공백 포함)를 기대했습니다. 하지만 GitHub은 올린 파일 이름의 공백을 바꿉니다. 그래서 회사 PC에서 "파일 없음"으로 실패했을 겁니다. dmg 이름을 Agent-Browser-0.1.0-arm64.dmg로 바꾸고, 이 어긋남을 잡는 테스트를 넣었습니다.

알아 두실 것

  • dmg 파일 이름이 바뀌었습니다: release/Agent-Browser-0.1.0-arm64.dmg.
  • git 커밋에는 작성자 이메일이 남습니다. GitHub에 올리면 저장소를 볼 수 있는 사람에게 보입니다. 비공개 저장소면 문제없습니다.
  • 남은 작은 것 7건(문서 표현, 드문 경우의 오류 문구, 테스트 보강)은 검사 보고서 "후속"에 있습니다. 급하지 않습니다.
