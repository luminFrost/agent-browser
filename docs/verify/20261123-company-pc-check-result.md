# 회사 PC 확인표 (v0.2.3) — 결과

결과: 2026-11-23 회사 PC(Apple Silicon, macOS 27.0.1), 앱 0.2.1 → 0.2.3 업데이트 뒤. 40항목 중 OK 23 · 결과 기록 4 · 건너뜀 1 · 모름 1 · 사람 확인 안 함 11 · **안 됨 0**.
- 사람 확인 안 함 11개는 Linux E2E(`ci.yml`)가 같은 동작을 보는 항목이라 사람 시간을 쓰지 않았다(사람 결정). 칸에 시험 이름을 적었다.
- 6장 이후 에이전트 쪽 일은 Claude Code가 `~/work/alpha`에서 `claude -p`로 시켰고, 6·7장 시각·앞 앱은 터미널에서 쟀다. 사람은 창을 숨기고·글을 치고·화면을 보고 알렸다.
- 모름: 9-4(승인 알림을 누르면 창이 앞으로 오는지), 9-2의 Dock 튐·배지. 다음 확인 때 본다.


Linux 시험 화면으로는 확인할 수 없는 Mac 동작을 회사 PC에서 사람이 따라 하며 확인한다. 카드 `20261123-qa-followups`(v0.2.2 확인표 `20261122-company-pc-check.md`에 v0.2.3에서 바뀐 것을 더했다).
항목마다 순서대로 하고 결과 칸에 `OK` / `안 됨` / `모름`과 한 줄 메모를 쓴다. 안 되면 그때 화면을 찍어 둔다.

**준비**
- Apple Silicon Mac, Claude Code, 프로젝트 폴더 두 개(예: `~/work/alpha`, `~/work/beta`).
- 이 문서는 v0.2.2의 사람 창 UI 보호·승인 알림에 QA 후속 수정(앱 메뉴, 에이전트가 고른 탭 보이기, 승인 대기 화면 지키기 등)이 들어간 v0.2.3을 확인한다. 1~10장은 v0.2.2 확인표와 같고 11장이 새로 생겼다.
