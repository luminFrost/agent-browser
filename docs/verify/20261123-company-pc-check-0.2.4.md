# 회사 PC 확인표 (v0.2.4)

Linux 시험 화면으로는 확인할 수 없는 Mac 동작을 회사 PC에서 사람이 따라 하며 확인한다. 카드 `20261123-update-notice`(v0.2.3 확인표 `20261123-company-pc-check.md`에 v0.2.4에서 바뀐 것을 12장으로 더했다).
항목마다 순서대로 하고 결과 칸에 `OK` / `안 됨` / `모름`과 한 줄 메모를 쓴다. 안 되면 그때 화면을 찍어 둔다.

**준비**
- Apple Silicon Mac, Claude Code, 프로젝트 폴더 두 개(예: `~/work/alpha`, `~/work/beta`).
- 이 문서는 v0.2.3에 화면 모드(기기·밝게·어둡게)와 앱 안 업데이트가 들어간 v0.2.4를 확인한다. 1~11장은 v0.2.3 확인표와 같고 12장이 새로 생겼다.
- v0.2.3 결과(`20261123-company-pc-check-result.md`)에서 이번에 꼭 사람이 볼 것: 9-2 Dock 튐·배지 `1`, 9-4 알림을 누르면 창이 앞으로 오는지, 9-5 허용 뒤 배지가 사라지는지, 9-6 Claude가 거부됐다고 말하는지, 11-1 주소창 Cmd+C·Cmd+V, 11-3 beta 요청의 알림·배지. 나머지 E2E가 보는 항목은 지난번처럼 건너뛰어도 된다(사람 결정, 결과 칸에 "E2E").

## 6. 최소화·Cmd+H
에이전트 세션은 사람 창 안에 있어서, 창이 안 보이면 페이지 그리기가 멈출 수 있다(ADR-0009). 그때 에이전트의 스크린샷·클릭이 멈추는지 본다.

| # | 순서 | 기대 | 결과 |
|---|---|---|---|
| 6-1 | alpha에 "example.com 스크린샷을 30초 간격으로 3번 찍어 줘"를 시키고 곧바로 사람 창을 최소화(노란 버튼) | 3번 다 찍힌다. 한 번에 30초 넘게 멈추지 않는다 | |
| 6-2 | 같은 일을 시키고 Cmd+H로 앱 숨기기 | 6-1과 같다 | |
| 6-3 | 창은 보이게 두고 내 탭을 보는 중에 alpha에 스크린샷·클릭을 시킨다 | 멈추지 않는다 | |
| 6-4 | 다른 앱 창이 사람 창을 완전히 덮은 상태에서 6-3 | 멈추지 않는다 | |

## 9. 승인 알림
| # | 순서 | 기대 | 결과 |
|---|---|---|---|
| 9-1 | 처음 알림이 올 때 macOS가 알림 허용을 묻는다 | 허용한다(시스템 설정 → 알림 → Agent Browser에서도 켤 수 있다) | |
| 9-2 | 다른 앱을 앞에 두고 alpha에 "https://httpbin.org/forms/post 폼을 채워서 제출해 줘" | Dock 아이콘이 한 번 튀고 배지 `1`. macOS 알림 `승인 요청 · alpha`(아래 줄 `httpbin.org · 폼 제출`)이 뜬다 | |
| 9-2a | 9-2에서 알림만 안 떴다면: 시스템 설정 → 알림 목록에 Agent Browser가 있는지 본다 | 결과를 적는다. Electron 45는 서명된 앱에서만 알림을 보이고 이 앱은 ad-hoc 서명이라 막힐 수 있다. 막혀도 Dock·배지·패널로 알 수 있으면 쓸 수 있다 | |
| 9-3 | 패널의 승인 줄을 본다 | 세션 이름과 "10분 뒤 자동 거부"가 보이고 시간이 줄어든다 | |

| 9-5 | **허용** | 제출이 진행되고 배지가 사라진다 | |
| 9-6 | 다시 제출하게 하고 **거부** | 제출되지 않고 배지가 사라진다. Claude가 거부됐다고 말한다 | |
| 9-7 | **따라 보기**를 켠 채 alpha에 제출을 시키고, 승인 전에 beta가 페이지를 옮기게 한다 | 화면이 alpha에 머문다(승인을 기다리는 세션을 보는 동안은 옮기지 않는다) | |
