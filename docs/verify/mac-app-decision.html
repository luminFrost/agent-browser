Mac 앱 묶기 — 정해 주실 것 하나

2026-11-14 · 검사 2회차 결과

결론: Mac 앱(.dmg)은 만들어졌고, 7개 조건 중 6개는 통과했습니다. Node 없이 실행되고, 보안 장치도 그대로이며, 끄면 깔끔하게 정리됩니다.
"두 번 열어도 하나만 뜬다" 하나만 두 번 연속 실패해서, 규칙대로 멈추고 여쭙니다.

무엇이 문제인가

  • 보통처럼 몇 번 클릭하는 경우는 괜찮습니다. 검사자가 0~0.9초 간격으로 여러 번, 컴퓨터가 바쁜 상태에서도 해 봤는데 문제가 없었습니다.
  • 그런데 0.008초 간격으로 120번 연달아 실행하는 극단적인 시험에서는 13번 중 4번 브라우저가 2~3개 떴습니다.
  • 원인: 앱을 열 때 "이미 켜져 있나?"를 Chromium 내부 장치로 확인합니다. 이 장치는 켜져 있는 쪽이 바빠서 대답이 늦으면 "멈췄다"고 보고 자리를 빼앗습니다.
  • 같은 이유로, 아주 드물게 막 켜지던 창이 꺼지거나, 컴퓨터가 시작 도중 꺼진 뒤 앱이 열리지 않을 가능성도 있습니다.

고르실 것

A. 확인 방식을 바꿔서 고친다추천
"이미 켜져 있나?"를 Chromium 장치 대신 앱이 직접 관리합니다. 켜져 있는 동안 런처가 표시를 들고 있고, 다시 열면 런처에게 "창을 앞으로" 신호만 보냅니다.
예상 30~40분 + 검사 1회 더. 극단적인 연속 실행에서도 하나만 뜨게 하는 것이 목표입니다.
B. 지금 상태로 마무리한다
"보통 사용(몇 번 클릭)에서는 하나만 뜬다"로 조건을 좁히고, 극단적인 연속 실행은 "알려진 한계"로 기록합니다.
바로 마무리 단계로 갈 수 있습니다. 드문 경우의 "창이 안 뜸"은 남습니다.
C. 여기서 멈춘다
코드는 그대로 두고 나중에 다시 봅니다.

지금 하실 일

곧 뜨는 질문 창에서 A / B / C 중 하나를 고르시면 됩니다.
