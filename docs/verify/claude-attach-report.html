Claude Code에서 바로 붙기 — 검사 결과

2026-11-15 · 작업 20261115-claude-attach · 첫 검사에서 통과 · 실작업 약 26분

결론: 이제 회사 PC에서 명령 한 줄만 실행하면 Claude Code가 이 브라우저를 씁니다. Claude Code 세션마다 자기 창이 하나씩 자동으로 생기고, 세션이 끝나면 그 창이 닫힙니다. 앱이 꺼져 있으면 켜서 붙습니다. 검사자가 실제 Claude Code로 붙여서 페이지 제목을 읽어 오는 것까지 확인했습니다.

지금 하실 일

  1. 아래 "남은 작은 것"의 첫 번째(사람이 창을 닫았을 때)를 지금 고칠지 정해 주세요. 그대로 두셔도 쓰는 데 문제는 없습니다.
  2. /aif-deliver를 입력하세요. 요약을 보여 드리고 승인을 받은 뒤 작업을 닫습니다. 그다음 ! git checkout main && git merge --ff-only feat/claude-attach로 main에 합치시면 됩니다.
  3. 회사 PC에서 할 일:
    • release/Agent Browser-0.1.0-arm64.dmg를 설치하고, 처음 한 번은 우클릭 → 열기로 엽니다.
    • 터미널에서 아래 한 줄을 실행합니다.
      claude mcp add --scope user agent-browser -- "/Applications/Agent Browser.app/Contents/Resources/agent-browser-mcp"
    자세한 안내는 저장소의 README.md에 있습니다.

된 것

바라던 것결과

세션마다 따로 창통과 — 동시에 3개를 붙여도 각자 자기 탭만 봄(사람 창도 안 보임)
세션이 끝나면 창 닫기통과 — 정상 종료, 종료 신호, 강제 종료(kill -9) 모두 5초 안에 닫힘

남은 작은 것 (급하지 않음)
