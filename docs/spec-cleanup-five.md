# Spec: 묶은 앱 정리 거리 5건
상태: 승인 (2026-11-15) · 구분: 남길 것 · 정본: 이 문서 (앱 동작은 `docs/spec.md`, 묶은 앱은 `docs/spec-mac-app.md`) · 규모: M · 검증 강도: 보통 · 작업: 20261115-cleanup-five
사람 결정 (2026-11-15): 범위 "5건 모두", 규모·강도 "M, 보통", 로그 "1MB 넘으면 교체"

## 가치
Mac 앱 검증에서 후속으로 남긴 Minor 5건(`docs/verify/20261114-mac-app-package.md` "후속")을 정리한다. 끄자마자 다시 열어도 앱이 뜨고, 기록 파일이 끝없이 커지지 않게 한다.

## 범위
- 한다: 아래 C1~C5.
- 안 한다: 서명·공증, 앱 동작(R1~R13) 변경, 새 라이브러리, 버전 번호 변경.

## 요구사항과 인수 사례 (= 완료 기준)
| # | 요구사항 | 인수 사례 (입력 → 기대 결과) | 확인 방법 |
|---|---|---|---|
| C1 | 끄는 중 다시 열기 | 묶은 앱을 끄기 시작한 뒤(런처에 SIGTERM) 0, 20, 50, 100, 300ms 뒤에 다시 연다. 간격마다 2번, 모두 10번 → 10번 모두 앱이 다시 켜진다(런처·브라우저 각각 1개, 사람 창이 화면에 보임) | 묶은 앱 E2E(`npm run test:dist`) |
| C2 | 실행 기록 크기 | 앱을 켤 때 `launcher.log`가 1MB(1,048,576바이트)를 넘으면 → 그 내용이 `launcher.log.1`로 옮겨지고(이전 `.1`은 덮어씀) `launcher.log`는 새로 시작한다. 1MB 이하면 그대로 이어 쓴다 | 단위 테스트 |
| C3 | 브라우저 인자 이름 한 곳에 | `--ab-hidden`·`--ab-downloads=`가 `src/shared/constants.ts`에 한 번만 정의되고 런처·브라우저가 그것을 쓴다 | `grep`으로 `src/`에 다른 문자열 정의가 없음 |
| C4 | 준비 전 실패 정리 | 브라우저가 준비 전에 끝나면 → `startApp`이 실패하고, 그 프로세스가 대기 타이머 때문에 남지 않고 3초 안에 스스로 끝난다(지금은 30초) | 단위 또는 E2E 테스트(별도 Node 프로세스로 실행해 끝나는 시간 측정) |
| C5 | 잘못된 설정 테스트 보강 | 잘못된 환경 값으로 열 때 → 테스트가 시작 프로세스 자신도 남지 않았음을 확인한다. 고의로 시작 프로세스를 남기면 이 테스트가 실패한다 | 묶은 앱 E2E + 고의로 깨뜨려 실패 확인 후 되돌림 |

확인 방법(공통): `npm run lint`, `npm test`, `npm run build`, `npm run test:dist`가 모두 통과한다(기존 동작 유지).

## 위험
- 로컬 앱만 바뀐다. 되돌리기: main을 이 작업 전 커밋으로 되돌리고 `npm run dist`.
